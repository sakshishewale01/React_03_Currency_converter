# 💱 Currency Converter

A responsive **Currency Converter** built with **React.js** that fetches exchange rates from an external API and converts currencies in real time.

## 🚀 Features

* 💰 Enter amount
* 🌎 Select source and target currencies
* 🔄 Swap currencies
* 💱 Convert using exchange-rate data
* 🌐 API integration
* 🪝 Custom React Hook
* 📱 Responsive UI

## 🛠️ Tech Stack

* React.js
* JavaScript
* Vite
* Tailwind CSS
* React `useState` & `useEffect`
* Currency API

## 🌐 API


```text
https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.json
```

The API provides the latest exchange rates for different currencies.
